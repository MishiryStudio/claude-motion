# Shorts من الحلقة الطويلة

بيطلّع شورتس/ريلز (1080×1920) من فيديو الحلقة: الحلقة كاملة في كارت في النص، والعنوان فوق، وكابشن عربي كلمة بكلمة تحت، وفي الآخر كارت CTA. الرندر كله على جهازك، ومش بيستهلك أي حاجة من Claude.

## أول مرة بس

```bash
npm install
```

## لكل شورت

1. انسخ فيديو الحلقة (نسخة، مش نقل) لـ `public/source.mp4`.
2. رندر:

```bash
npm run short -- E01 1 --draft    # نسخة سريعة بنص الجودة علشان تراجع
npm run short -- E01 1            # النسخة النهائية
npm run short -- E01 all          # كل الشورتس مرة واحدة
```

الملف النهائي هيطلع في `out/shorts/E01-1.mp4`، وصور المراجعة في `out/sheets/`.

## تعدّل إيه وفين: `shorts/E01.json`

| الحقل | معناه |
|---|---|
| `clips[].title` | عنوان الـ hook. الكلمة اللي بين `*نجمتين*` بتطلع بالأصفر |
| `clips[].kicker` | السطر الصغير اللي فوق العنوان |
| `clips[].segments` | أجزاء الحلقة بالثواني `[البداية, النهاية]`. ممكن تحط أكتر من جزء |
| `brand` | الألوان، واللوجو: حط الملف في `public/logo.png` واكتب `"logo": "logo.png"` |
| `cta` | نص كارت النهاية |
| `replace` | تحويل كلام في الكابشن، مثلاً "ألفين وتمانية" ← "2008" |

## حلقة جديدة

انسخ `E01.json` باسم `E02.json`، وغيّر `srt` و`clips`، وحط ملف الـ SRT في `shorts/`. وبعدين:

```bash
npm run short -- E02 1
```

## لو حاجة مش مظبوطة

- **الكابشن متأخر أو سابق الصوت:** التوقيت جاي من ملف الـ SRT. اتأكد إنه متظبط على الفيديو النهائي.
- **القطع بياكل أول كلمة أو آخرها:** وسّع الجزء في `segments` بـ 0.2 ثانية.
- **عايز تشوف التعديلات على طول:** شغّل `npm run short -- E01 1 --prep` وبعدين `npm run studio`، واختار `Short`. الـ props موجودة في `public/shorts/E01-1/props.json`.
